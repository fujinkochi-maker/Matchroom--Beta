# Matchroom Beta 
Matchroom Beta is a web application created by esdeekido for the Roblox game Boxing Beta. 
Built to support both the Matchroom website and the Beta-Rec Discord bot, it provides a centralized platform for managing boxing leagues, fighters, and match records.

## Purpose 
Matchroom Beta was developed for my Roblox Boxing Beta league to simplify fighter management and record keeping. It serves as the central hub for tracking players, maintaining accurate boxing records, organizing events, and supporting both the website and the Beta-Rec Discord bot with a unified system.

### 🌐 Live Demo
Website: https://matchroom-beta.vercel.app/

Matchroom Beta provides a centralized platform for managing Roblox Boxing Beta leagues, fighters, events, and records. It works alongside the Beta-Rec Discord bot to keep player statistics, fight history, and league data synchronized across both the web application and Discord.
